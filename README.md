# BluetoothFinder

Android приложение для поиска выбранных Bluetooth устройств. Сохраняет локальную историю подключений и отключений с координатами **телефона**. Карта показывает точки и ориентировочную область поиска. Экран «Поиск рядом» показывает RSSI и подсказывает направление после нескольких шагов, если устройство отвечает на сканирование.

## Возможности и ограничения

- Мониторинг работает через foreground service с постоянным уведомлением. Устройство нужно сначала сопрячь в настройках Android и выбрать в приложении.
- При мониторинге позиция обновляется примерно раз в 20 секунд в сбалансированном режиме; при событии подключения или отключения запрашивается более точная позиция. Реальная точность и задержка зависят от телефона и условий.
- История хранится локально в Room. Для старых записей может быть известна только точка отключения.
- Карта использует тайлы OpenStreetMap; для новых участков нужен интернет. Координаты, маркеры и история доступны без сети.
- RSSI не измеряет расстояние. Стены, тело человека и положение наушников меняют сигнал. Если устройство не передаёт обнаруживаемый сигнал, наведение недоступно.
- После перезагрузки система пытается возобновить сервис. Ограничения производителя, принудительная остановка приложения и отзыв разрешений могут помешать запуску.

## Разрешения

Bluetooth Connect нужен для событий подключения, Bluetooth Scan — для поиска рядом, геолокация — для координат телефона, распознавание активности — для счётчика шагов. Для координат при закрытом приложении выдайте геолокацию «Всегда» в настройках Android. Данные хранятся локально; резервное копирование отключено.

## Сборка и тесты

Нужны JDK 21, Android SDK Platform 35 и Build Tools 35.0.0. Локальные зависимости и SDK находятся в `.toolchain` (игнорируется Git). В PowerShell из корня проекта:

```powershell
.\build.ps1
.\build.ps1 testDebugUnitTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Установка: `adb install -r app/build/outputs/apk/debug/app-debug.apk`.

На Windows JUnit worker может не находить классы, если путь проекта содержит кириллицу. В таком случае запустите тесты через путь без кириллицы (например, junction на каталог проекта); `build.ps1` поддерживает такой путь.
